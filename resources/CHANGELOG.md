# 更新日志

本文件仅记录当前待发布版本。每次准备正式版时，按 `CMakeLists.txt` 中的版本号重写本文件，不追加历史版本或 Unreleased 章节。

## [0.5.0]

### 上游同步

- 基于上游 CirrusMusic v0.5.0，保留网易云音乐浏览、搜索、歌单、播客、播放引擎、逐字歌词、一起听及桌面集成。
- 同步网易云网页“在客户端打开”、滚轮速度设置、Windows 原生标题栏主题和任务栏播放控制等更新；网页协议接管支持 Linux 和 Windows，macOS 暂不支持。
- 沿用上游 Linux Unix socket 播放状态与歌词接口，适配实际播放音源和字幕时序。

### 本项目新增与调整

- 增加默认关闭的 Bilibili 辅助音源开关：网易云因权限受限或只提供试听流时，按歌名、歌手和时长匹配 B 站视频及分 P，并显示实际音源。
- Bilibili 播放优先使用对应视频及分 P 的字幕；字幕缺失或为空时使用网易云歌词。字幕保留逐行时间，不伪造逐字时间。
- 支持粘贴、校验和清除 Bilibili Cookie，并使用系统钥匙串保存凭据。
- 更新检查指向本仓库的 GitHub Releases；Windows 安装器按 CPU 架构选择，下载后校验 SHA-256。
- 完善 Windows、macOS 运行时缓存目录准备：创建时设置原生私有权限，统一核验所有者、权限和链接；歌曲、封面、歌曲信息和歌词缓存沿用同一链路，补充重启复用、账号隔离及播放中清理回归。
- 统一原生多平台构建：Arch、Debian、Fedora 各支持 x86_64 / ARM64，Windows 支持 x64 / ARM64，macOS 支持 Apple Silicon / Intel。
- 所有 Linux 目标统一使用发行版官方 FFmpeg，共享库依赖由原生包工具生成；停止 Linux FFmpeg 源码编译及私有部署，保留 Windows/macOS 现有方式。Fedora 官方库缺少 E-AC-3 时明确拒绝该编码，正常网易云 MP3/FLAC 与 B 站 AAC/FLAC 不受此限制影响。
- Release 先检查版本、Tag 和发布说明，再运行 CI；CI 全部通过后并行构建三个平台，所有构建成功后统一校验产物并发布。
- README 改为说明本项目与上游的关系和功能差异；移除安装、Star History 章节及 VS Code 工作区配置。

### 未引入的功能与限制

- 不提供上游云盘页面，也不提供本地音乐上传、云盘歌曲删除、纠错或取消关联入口。
- Bilibili 音源的匹配和音质取决于实际资源；播放 B 站音源时不向网易云上报听歌记录，也不支持一起听。
- 详细播放状态与歌词导出仅支持 Linux，默认关闭。
- 不再提供 AppImage 和旧 AUR 打包入口；Windows 安装器未代码签名，macOS 包未经过 Apple 公证。
